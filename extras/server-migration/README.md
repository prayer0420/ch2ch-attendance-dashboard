# 서버 이관 작업

Linux/Xen 서버 이관 실습과 문서 제작에 필요한 자료를 모은 독립 작업 영역입니다.

| 위치 | 용도 |
|---|---|
| `CODEX_MASTER_HANDOFF.md` | 전체 이관 맥락과 재개 지점 |
| `산출물/` | 최종 Word 문서 등 전달용 산출물 |
| `output/` | 생성된 PDF와 HTML 런북 |
| `qa/` | 렌더링 이미지와 시각 검수 자료 |
| `tools/` | 문서·PDF 생성 및 검수 도구 |
| `tmp/` | 생성 과정에서 사용하는 보조 스크립트와 자료 |

`tools`와 `tmp`의 스크립트는 이 폴더를 기준으로 산출물 경로를 계산하므로 프로젝트가 다른 PC로 이동해도 같은 구조로 동작합니다. 외부 원본 파일을 직접 지정한 스크립트는 실행 전에 해당 입력 파일이 현재 PC에 있는지 확인해야 합니다.
