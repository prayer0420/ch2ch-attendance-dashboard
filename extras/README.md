# 기타 프로그램과 보조 자료

CH2CH 출석체크·QR체크·예배일지 본체와 직접 관련되지 않은 작업을 한곳에 모았습니다. 앱 본체는 계속 프로젝트 루트의 `app`, `components`, `lib`, `runner`, `scripts`에서 실행됩니다.

| 폴더 | 내용 |
|---|---|
| `server-migration/` | Linux/Xen 서버 이관 문서, 산출물, 생성 도구, 검수 자료 |
| `transcription/` | 녹음 전사 문서, 전사 결과, 실행 도구 |
| `qemu-oracle-linux/` | Windows QEMU·Oracle Linux 실습 인수인계 문서 |

이 폴더는 Windows 설치 앱 패키지에서 제외됩니다. 보조 작업을 다시 시작할 때는 해당 하위 폴더의 `README.md`를 먼저 확인하세요.
