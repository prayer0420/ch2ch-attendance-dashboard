# 예배일지 회계 입력 설계

## 목표

예배일지를 만들 때 출석 Google Sheet와 주보 HWP에 더해 회계 자료를 함께 입력하고, 선택한 예배 날짜의 감사헌금 내역을 자동 정리하여 같은 예배일지에 저장한다.

## 범위

- 회계 원본은 `엑셀 파일`과 `Google Sheet`를 모두 지원한다.
- 화면에서는 두 입력 방식을 탭으로 구분하며 한 번의 실행에서는 하나만 사용한다.
- 회계 자료 중 `감사헌금` 영역만 읽는다.
- DB나 별도 백엔드 서비스는 추가하지 않는다.
- 기존 날짜별 로컬 예배일지 저장 방식을 유지한다.

## 사용자 흐름

1. 사용자가 예배 날짜, 출석 Sheet, 주보 HWP와 새가족 정보를 입력한다.
2. `회계 자료`에서 `엑셀 파일` 또는 `Google Sheet` 탭을 선택한다.
3. 엑셀 파일을 올리거나 Google Sheet URL을 입력한다.
4. `예배일지 만들기`를 실행한다.
5. 시스템은 탭 이름 또는 탭 상단의 날짜 표기에서 선택 날짜와 일치하는 회계 탭을 찾는다. 여러 후보가 있으면 가장 오른쪽 탭을 우선한다.
6. 감사헌금 영역을 읽어 이름, 금액, 감사내용을 정리한다.
7. 출석, 예배 정보, 광고, 감사헌금이 포함된 미리보기를 보여주고 날짜별로 저장한다.

## 회계 탭 탐색

- 탭 이름과 각 탭 상단 8개 행에서 선택 날짜의 `YYYY-MM-DD`, `YYYY.MM.DD`, `YY-MM-DD`, `M/D`, `M월 D일` 표현을 인식한다.
- 일치하는 탭이 여러 개면 통상 최신 자료가 있는 가장 오른쪽 탭을 사용한다.
- 날짜와 일치하는 탭을 찾지 못하면 임의의 탭을 읽지 않는다.
- 실패 응답에는 선택 날짜와 발견된 탭 이름 전체를 포함한다.

## 감사헌금 추출과 정렬

- `감사헌금` 표제 이후의 이름, 금액, 감사내용 열을 탐색한다.
- 이름이 없는 합계·소계 행은 개인 내역에서 제외한다.
- 금액은 쉼표, 통화 기호, 숫자 셀을 허용하고 원 단위 정수로 정규화한다.
- 감사내용이 있는 항목을 이름 가나다순으로 먼저 배치한다.
- 감사내용이 없는 항목을 이름 가나다순으로 이어서 배치한다.
- 미리보기 표시는 `이름 (금액원) 감사내용`을 기본 형식으로 한다.
- 감사헌금 총액은 유효한 개인 내역의 금액 합계로 계산한다.

## 코드 경계

- 회계 원본 읽기와 감사헌금 분석은 예배일지 본체와 분리된 모듈에 둔다.
- 예배일지 API는 선택한 회계 원본을 읽은 뒤 정규화된 회계 결과만 예배일지 모델에 결합한다.
- 화면 컴포넌트는 원본 선택, 파일·URL 입력, 결과 표시만 담당한다.
- 회계 전용 검증 스크립트와 문서는 회계 폴더에 두어 다른 기능 작업에서 읽을 필요가 없게 한다.

## 데이터 형태

예배일지에는 다음 회계 데이터가 추가된다.

```ts
type ThanksgivingOffering = {
  name: string;
  amount: number;
  note: string;
};

type JournalAccounting = {
  sourceType: "excel" | "google-sheet";
  sourceName: string;
  sheetTab: string;
  total: number;
  thanksgiving: ThanksgivingOffering[];
};
```

기존에 저장된 예배일지는 `accounting` 값이 없어도 정상적으로 표시한다.

## 오류 처리

- 엑셀 확장자가 `.xlsx` 또는 `.xls`가 아니면 입력 단계에서 안내한다.
- Google Sheet URL은 네이티브 Sheet와 Drive에서 Sheets로 열리는 `.xlsx` 파일을 모두 허용한다.
- Google Sheet URL 형식이 아니거나 원본 파일을 내려받을 권한이 없으면 원인과 공유 권한 확인 방법을 표시한다.
- 날짜 탭, 감사헌금 표제, 이름·금액 열을 찾지 못하면 각각 구분된 오류를 표시한다.
- 회계 분석 실패 시 불완전한 예배일지를 저장하지 않는다.

## 화면 설계

- 기존 종이 예배일지와 어울리는 절제된 문서형 디자인을 유지한다.
- 입력 카드 안에 `회계 자료` 섹션과 두 개의 소스 탭을 추가한다.
- 미리보기에는 감사내용이 있는 내역과 없는 내역의 순서가 그대로 드러나는 감사헌금 영역과 총액을 추가한다.
- 모바일에서는 한 열, 넓은 화면에서는 입력과 안내가 자연스럽게 나뉘도록 기존 반응형 구조를 유지한다.

## 검증

- 날짜별 탭 선택과 오른쪽 탭 우선 규칙을 자동 검증한다.
- 금액 정규화, 합계 행 제외, 감사내용 유무별·가나다순 정렬을 자동 검증한다.
- 엑셀 원본과 Google Sheet 원본이 같은 정규화 결과를 만드는지 검증한다.
- 기존 저장 데이터에 회계 필드가 없어도 미리보기가 깨지지 않는지 확인한다.
- 타입 검사와 프로덕션 빌드를 통과해야 한다.
