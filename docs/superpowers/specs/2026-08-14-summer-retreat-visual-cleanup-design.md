# 2026 여름수련회 시트 운영 화면 정리 설계

## 목적

서기팀이 최종 작업 대상 Google Sheet를 열었을 때 자동 집계, 직접 작성, 참고 메모를 빠르게 구분하고 수기로 확정하기 쉽도록 4개 운영 탭의 화면을 정리한다.

## 범위

- 대상: `참석자 명단`, `숙박·방편성`, `이동수단`, `카풀 명단`
- 기존 `취합(아직X)`, `방배치`, `조편성`, `시트3`, `출석부`는 변경하지 않는다.
- 25개 원본 파일에는 어떤 쓰기도 하지 않는다.
- 기존 `IMPORTRANGE`, `FILTER`, `TEXTJOIN`, `COUNTIF`, `SUM` 수식과 원본 링크는 보존한다.

## 화면 원칙

- 파란색 계열: 원본에서 읽어오는 참고·집계값
- 노란색 계열: 서기팀이 직접 확정·작성하는 값
- 회색 계열: 링크·비고·설명
- 제목·헤더·합계 행을 일관된 색과 굵기로 표시한다.
- 상단 안내문은 짧게 줄이고, 첫 열과 헤더 행을 고정한다.
- `자동`이라는 기술 용어는 운영 화면에서 최소화하고, 서기가 실제로 관리하는 열 이름을 우선한다.

## 탭별 정리

### 참석자 명단

전체 명단과 날짜별 명단은 유지한다. `최종 명단`, `서기팀 메모` 열을 노란색 입력 영역으로 강조하고, 원본 집계·날짜별 상세는 참고 영역으로 구분한다.

### 숙박·방편성

목·금 숙박 인원과 숙박 상세는 유지한다. 방 번호·방 배정 명단·비고를 직접 작성 영역으로 강조하고, 방 배정 틀은 별도 운영 영역으로 읽기 쉽게 유지한다.

### 이동수단

날짜별 요약과 상세 명단은 유지한다. 실제 운영 시 서기가 작성하는 최종 차량 수와 비고를 입력 영역으로 강조하며, 원본 응답 기반 값은 참고 영역으로 둔다.

### 카풀 명단

운전자·탑승자·출발/복귀·상태·비고를 한 번에 입력할 수 있도록 전체 입력 표를 노란색 계열로 정리한다. 불필요한 설명은 줄인다.

## 검증 기준

- 4개 운영 탭의 제목·헤더·입력/참고 영역 색상이 일관된다.
- 기존 데이터와 수식이 유지된다.
- 25개 원본 링크가 유지된다.
- `취합(아직X)` 및 원본 파일에 쓰기 흔적이 없다.
