하나의 서비스,
웹에서도 앱에서도.

사용 중인 CH2CH 웹 주소로 연결하세요.
이 앱은 출석 실행기를 새로 켜거나 기존 서비스를 종료하지 않습니다.

외부 서버는 HTTPS, 이 PC의 서비스는 localhost 주소를 사용합니다. 비밀번호나 API 키는 여기에 입력하지 마세요.

이 PC에서 기존 서비스를 쓰고 있다면
기존 start-local.cmd로 웹 서비스를 켠 후 해당 주소에 연결하세요.

서버에 배포한 서비스를 쓰고 있다면
운영 HTTPS 주소를 입력하세요. 모바일도 같은 주소에서 홈 화면에 추가할 수 있습니다.

출석·예배일지 자료는 기존 서비스에서 관리합니다. 서버 주소 변경: 앱 메뉴 또는 Ctrl+,
