# 설치 후 설정

1. `CH2CH 출석체크 Setup.exe`를 실행합니다.
2. 설치된 프로젝트 폴더에 `.env.local`을 만듭니다.
3. `.env.example`의 필수 항목을 실제 값으로 채웁니다.
4. 프로젝트 폴더에서 `npm run install-browsers`를 한 번 실행합니다.
5. 바탕화면의 `CH2CH 출석체크`를 실행합니다.

`.env.local`은 설치 프로그램에 포함되지 않습니다. CH2CH 아이디, 비밀번호, Supabase Service Role Key를 GitHub나 설치 파일에 넣지 마세요.
